Interpreting the signals:

  • Signal Quality: Excellent (≥-85 dBm) → Good (≥-95) → Fair (≥-105) → Weak
  • Registration (CREG): 0=Not registered, 1=Home, 2=Searching, 5=Roaming
  • Packet Domain (CEREG): Same scale. LTE registration separate from voice.
  • Data Attach (CGATT): 0=Detached, 1=Attached. Must be 1 for data.
  • Slow NETLIGHT blink (15s+): Usually indicates mode active but idle. Check power supply (should be ≥4V @ 800mA capacity).
RF Interference Test

Disable GPS to check if it's interfering with LTE signal. Watch RSSI and registration before/after. If signal improves when GPS is off, RF interference is likely.

ELQDrone is a field console built around ESP32, SIM7600G, GPS, SMS, and SD-hosted web tools. It was designed to support practical modem control, telemetry, and location-aware messaging.

Roadmap

Future updates

Planned communication upgrades for the next hardware revision and field testing cycle.

Hybrid LoRa link

Planned

The next version is planned to use a hybrid LoRa communication layer between two ESP32 nodes: one mounted on the base station and one mounted on the drone. The base-side ESP32 will act as the coordinator, while the drone-side ESP32 will exchange link data, control messages, and telemetry updates over LoRa for longer-range, low-bandwidth communication.

Base node ESP32 coordinator
Handles routing, command relay, and link supervision.
Air node ESP32 on drone
Sends status, acknowledgements, and selected control data.
Link type LoRa uplink/downlink
Optimized for range, resilience, and lower data rate messaging.
Goal Hybrid comms
Keep LTE, GPS, and Wi-Fi tools while adding a dedicated long-range path.

Planned workflow

  • Base ESP32 sends a configured LoRa frequency/channel and link settings to the drone unit.
  • Drone ESP32 listens for commands, returns heartbeat packets, and relays critical telemetry.
  • The portal will later show link quality, packet health, and handshake status.
  • Hybrid mode will keep the LTE modem available for internet tasks while LoRa handles direct field communication.
